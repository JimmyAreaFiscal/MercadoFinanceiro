# MercadoFinanceiro

This is a personal repo where I've tried to transform the candle patterns (from the book "Candlestick: um método para ampliar lucros na bolsa de valores") into python functions, in an attempt to improve data understand and automatic operations (algotrading).

Please enjoy the repo.


Files:

## backtesting.py

This is a file where I hold some backtesting functions. The idea here is not to backtest, but to replicate signal functions from other backtesting libraries. 

## conexao.py

This is responsible for data pipeline using MetaTrader 5.

## livro_candlesticks.ipynb

This is the main file, where you can read and understand the candle patterns.
